# Clean UI — AI 티 안 나는 화면 만들기

출처: hallmark(github.com/Nutlope/hallmark, MIT)의 안티 슬롭 규칙과 Uber DESIGN.md 분석을 바탕으로,
지하철 대시보드 작업에서 실제로 효과 있었던 것만 추려 한국어 화면 기준으로 정리했다.

## 작업 순서

1. **무엇을 위한 화면인지 한 줄로 정한다.** "휴대폰에서 지금 붐비는 역을 3초 안에 본다"처럼. 이 문장이 모든 판단 기준이다.
2. **구조부터 정한다.** 색·폰트보다 먼저, 무엇이 가장 크고 무엇이 작은지(위계)와 섹션 순서를 정한다.
3. **토큰을 먼저 만든다.** 색·글꼴·간격을 CSS 변수로 `:root`에 정의하고, 본문에서는 변수만 쓴다. 중간에 임의 값을 새로 만들지 않는다.
4. **구현한다.**
5. **아래 '슬롭 체크리스트'를 돌린다.** 하나라도 "예"면 고친다.
6. **실제 화면으로 확인한다.** 폭 360px·1100px, 밝은/어두운 모드에서 스크린샷을 찍어 본다. 코드만 보고 끝내지 않는다.

## 피해야 할 AI 패턴과 대안

| AI 패턴 | 대신 이렇게 |
|---|---|
| 보라→파랑 그라디언트 배경·글자 | 기준색 1개 + 강조색 1개. 그라디언트 글자는 어떤 경우에도 금지 |
| Inter·Roboto·시스템 폰트(또는 Inter 기반 Pretendard)를 큰 제목에 사용 | 개성 있는 제목용 폰트 + 차분한 본문 폰트, 두 벌로 역할을 나눈다 |
| 모든 요소 가운데 정렬 | 기본은 왼쪽 정렬. 대칭을 한 번은 깬다(제목 왼쪽, 버튼 오른쪽 등) |
| 아이콘 위에 제목 얹은 똑같은 카드 3개 | 카드 크기에 강약을 준다. 가장 중요한 하나를 크게, 나머지는 작게. 아이콘 대신 글자로 시작 |
| 카드 안에 카드 | 한 단계만. 안쪽은 구분선이나 여백으로 나눈다 |
| 이모지(✨🚀✅)를 아이콘으로 사용 | 아이콘이 꼭 필요하면 한 가지 아이콘 세트만. 아니면 빼고 글자로 |
| 모든 섹션이 같은 여백·같은 모양 | 섹션마다 리듬을 바꾼다(검은 띠, 구분선, 큰 숫자 하나 등) |
| 흔한 상단 메뉴바 | 주제에 맞는 모양을 고른다(지하철이면 역 안내판, 신문이면 마스트헤드, 도구면 명령창) |
| 제목 속 기울임(이탤릭) 강조 단어 | 제목은 바로 세운 글자. 강조는 굵기·색·밑줄로 |
| 화면에 이미 보이는 결과에 "성공!" 토스트 | 결과가 보이면 조용히 끝낸다. 알림은 실패나 안 보이는 결과에만 |

## 기본 규칙

### 글꼴
- **최대 2벌 + 예외 1벌.** 제목용 1, 본문용 1. 세 번째는 로고나 큰 숫자 한 곳 정도에만.
- **한글 제목용 후보:** Black Han Sans(굵고 넓은 간판 느낌), Do Hyeon(좁은 표지판 느낌), Gmarket Sans Bold, 여기어때 잘난체 등. 큰 글씨가 세로로 길쭉해 보이면 폭이 넓은 폰트로 바꾼다.
- **한글 본문용 후보:** KoPubWorld 돋움, Pretendard, Noto Sans KR, SUIT.
- **한글 웹폰트는 꼭 줄여서(서브셋) 쓴다.** 원본은 한 벌에 수 MB다. 자주 쓰는 한글 2,350자 + 영문·숫자·기호만 남기면 150KB 안팎이 된다(`pyftsubset --flavor=woff2`). 빠진 드문 글자는 기본 폰트로 자동 대체된다.
- 폰트 사용 조건(OFL 등)을 확인하고, 필요하면 라이선스 파일을 폰트 옆에 둔다.
- 숫자가 줄 맞춰 나와야 하는 곳(표·순위·통계)에는 `font-variant-numeric: tabular-nums`.
- 본문 16px 기준. 휴대폰 입력칸은 16px 미만이면 아이폰이 자동 확대하니 16px 이상.

### 색
- 바탕은 무채색, 색은 **의미가 있을 때만** 쓴다(데이터 계열, 상태: 여유/보통/붐빔 등).
- 강조색 면적은 한 화면의 **5% 미만**.
- 순수 `#000`은 피하고 아주 살짝 색을 섞은 검정(`#111214` 등)을 쓴다.
- 노란 바탕에 흰 글씨처럼 대비가 약한 조합은 검은 글씨로 바꾼다. 본문 대비 4.5:1, 큰 글씨 3:1 이상.
- 어두운 모드는 변수만 바꿔 뒤집는다(`prefers-color-scheme`). 바탕을 바꿨으면 그 위 글자색도 함께 바꿨는지 확인한다.

### 간격·모양
- 간격은 **4의 배수**만(4, 8, 12, 16, 20, 24, 32). 17px, 6px, 10px 같은 값은 AI 티.
- 모서리 둥글기는 한 체계로: 버튼·칩은 알약(999px), 카드는 16px, 입력칸은 8px처럼 역할별로 고정.
- 그림자는 떠 있는 것(툴팁, 팝업)에만. 기본 카드는 평평하게.

### 레이아웃
- 화면 폭 320~1920px 어디서도 가로 스크롤이 생기면 안 된다. `html, body { overflow-x: clip; }`
- 가로로 나란한 줄(버튼 + 글자)은 `align-items: center`.
- 같은 종류 카드가 여러 개면 **가장 중요한 하나를 전체 폭으로 크게**, 나머지는 작게 나열한다.
- 휴대폰에서 표는 칸 여백을 줄이고, 긴 열 제목은 짧게 바꾼다("가장 붐비는 시간" → "피크").

### 움직임·반응
- `transition: all` 금지. 바뀌는 속성만 지정한다.
- 튕기는 애니메이션, 모든 요소에 hover 확대 금지.
- 모든 애니메이션에 `prefers-reduced-motion` 대안을 둔다.
- 마우스 올림(hover)으로만 보이는 정보는 휴대폰에서 안 보인다. 누르기(tap)로도 열리게 한다.
- 키보드 포커스 표시(`:focus-visible`)는 즉시 보이게. 눌림(`:active`) 상태도 만든다.

### 차트(대시보드)
- SVG 차트는 **실제 화면 폭으로 다시 그린다.** 큰 viewBox를 줄여서 보여 주면 휴대폰에서 글자가 5px까지 작아진다. `ResizeObserver`로 폭이 바뀔 때 다시 그린다.
- 축 글자 13px 이상, 좁은 화면에서는 눈금 간격을 넓힌다.
- 강조할 대상(내가 고른 역 등)만 진한 색, 나머지는 회색.

## 문구 말투

- 버튼·제목은 명사형으로 짧게: "화면 다시 읽기" → "새로고침", "지금 주변에 있는 사람" → "현재 인구", "앞으로 12시간 예상 혼잡도" → "12시간 예측".
- "~해 주세요", "~드립니다", "한눈에", "손쉽게", "스마트한" 같은 친절체·홍보체를 뺀다.
- 오류 문구는 **무슨 일이 생겼고 다음에 어떻게 되는지**만: "서울 자료를 불러오지 못했습니다. 1분 뒤 자동으로 다시 시도합니다."
- 실제 상황과 다른 안내를 하지 않는다(인터넷이 잠깐 끊긴 것을 "자료가 아직 없다"고 말하지 않기).
- "Jane Doe", "Acme" 같은 가짜 이름·지어낸 수치를 넣지 않는다.

UI가 없는 프로그램(명령줄 도구, 스크립트 메시지)에도 같은 말투를 쓴다: 짧게, 사실만, 다음 행동이 있으면 그것만.

## 슬롭 체크리스트 (모두 "아니오"여야 통과)

1. 큰 제목 폰트가 Inter·Roboto·시스템 기본(또는 그 파생)인가?
2. 그라디언트 글자나 보라·파랑 그라디언트 배경이 있는가?
3. 아이콘 + 제목으로 된 똑같은 카드가 3개 이상 나란히 있는가?
4. 카드 안에 카드가 있는가?
5. 제목·버튼·설명이 모두 가운데 한 줄에 쌓여 있는가?
6. 순수 `#000`을 기본색으로 쓰는가?
7. 강조색이 한 화면의 5%를 넘게 칠해져 있는가?
8. 4의 배수가 아닌 여백·간격이 있는가?
9. 글꼴이 세 벌을 넘는가?
10. 제목에 기울임 글자가 있는가?
11. 이모지를 아이콘 대신 썼는가?
12. `transition: all`이나 모든 요소 hover 확대가 있는가?
13. 320~1920px 사이 어떤 폭에서 가로 스크롤이 생기는가?
14. 휴대폰 폭에서 차트·표 글자가 12px보다 작아지는가?
15. hover로만 볼 수 있는 정보가 있는가?
16. 대비가 기준(본문 4.5:1)보다 낮은 글자가 있는가?
17. 휴대폰 입력칸 글자가 16px보다 작은가?
18. 버튼·탭에 `:focus-visible`이나 `:active` 상태가 없는가?
19. "~해 주세요", "손쉽게" 같은 AI 말투나 실제와 다른 안내 문구가 있는가?
20. 실제 화면(360px·1100px, 밝은/어두운 모드)을 스크린샷으로 확인하지 않았는가?

## 사용법

- Claude Code에서: 이 파일을 `~/.claude/skills/clean-ui/SKILL.md`(모든 프로젝트) 또는 `프로젝트/.claude/skills/clean-ui/SKILL.md`(그 프로젝트만)에 두면, 화면 작업 때 자동으로 참고한다. 직접 부르려면 `/clean-ui`.
- 다른 AI 도구에서: 이 내용을 그대로 붙여 넣고 "이 규칙대로 만들어 줘" 또는 "이 체크리스트로 지금 화면을 점검만 해 줘"라고 요청한다.
